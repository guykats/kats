# Family Hub

A mobile-first web app for managing family things.

- **Calendar** — a Google Calendar-style month board. Swipe left/right (or use the arrow buttons) to move between months, tap a day to add or remove events.
- **Shopping** — a shared shopping list. Add items, check them off, or remove them.

Data is stored locally in the browser (`localStorage`), no backend required.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
